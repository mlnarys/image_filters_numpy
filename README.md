# 🧪 Лабораторная работа: Обработка изображений с использованием NumPy

![Python](https://img.shields.io/badge/Python-3.11-blue)
[![NumPy](https://img.shields.io/badge/NumPy-1.27-lightblue)](https://numpy.org/)

---

## 🎯 Цель работы
Закрепить навыки работы с NumPy через реализацию базовых фильтров и преобразований изображений вручную, без использования специализированных библиотек компьютерного зрения.

## 🗂 Что изучается в проекте

- Чтение изображений и представление их как массива NumPy

- Применение фильтров: размытие (Blur), резкость (Sharpen), детектор границ (Sobel, Laplacian)

- Реализация свёртки (convolution) вручную

- Бинаризация (thresholding)

- Изменение яркости и контраста изображения

## 📁 Подготовка

Для работы с проектом требуется Python и следующие библиотеки:

- `numpy `— для работы с массивами и математических операций

- `matplotlib` — для отображения изображений

- `Pillow (PIL)` — для чтения изображений

  

## Установка зависимостей:

`pip install numpy matplotlib pillow`



## 🔽 Основные шаги работы

- Загрузка изображения и представление его как NumPy-массива.

- Преобразование в grayscale для дальнейшей обработки.

- Применение фильтров:

  - Median filter 3×3 для удаления шума
  
  - Размытие (Gaussian blur)
  
  - Резкость (Sharpen)
  
  - Эффект тиснения (Emboss)
  
  - Детектор границ (Sobel)
  
  - Регулировка яркости и контраста изображения.
  
  - Бинаризация изображения по порогу.



## 📌 Итог

Проект демонстрирует базовые техники обработки изображений, позволяет экспериментировать с фильтрами и их параметрами, а также закрепляет практические навыки работы с NumPy и матрицами изображений.
